📊 구글 스프레드시트 (Apps Script) 연동 설정

선생님의 구글 드라이브 스프레드시트와 연결하여 [🔄 시트 불러오기] 및 [💾 시트에 결과 저장] 기능을 활용할 수 있습니다.

🛠️ 3분 만에 구글 시트 웹 앱 만들기 안내:
  1. 구글 스프레드시트 생성 후 확장 프로그램 > Apps Script 클릭
  2. 아래 예시 코드를 붙여넣고 상단 [배포] > [새 배포] 선택
  3. 유형: 웹 앱, 액세스 권한: 모든 사용자(Anyone) 설정 후 배포
  4. 발급된 /exec URL을 위 입력창에 등록하면 완료!
function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  // 시트에서 학생명과 역할명 읽어오기
  var data = sheet.getDataRange().getValues();
  return ContentService.createTextOutput(JSON.stringify({status: "ok", data: data}))
    .setMimeType(ContentService.MimeType.JSON);
}
